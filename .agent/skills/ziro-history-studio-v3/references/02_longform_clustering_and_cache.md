# Dynamic Long-Form Clustering & Strict `.cache/` Architecture

Long-form historical documentaries (`15–35 minutes`, `450–900+ seconds` per half-hour) CANNOT be authored or rendered as a single monolithic 25-minute JavaScript scene without context-window degradation and painful re-render cycles. `Ziro-History-Studio-v3` solves this via **Dynamic Adaptive Clustering** and **Zero-Drift Sample Slicing**.

---

## 1. Input Trio Contract (`episodes/<EP_ID>/1_input/`)
Every episode starts with 3 clean files in `episodes/<EP_ID>/1_input/`:
1. `voice.MP3` (or `voice.mp3`): Full master narration voiceover.
2. `kich_ban_loi_dan.txt`: Plain 1-to-1 spoken lines matching `voice.MP3`.
3. `kich_ban_chia_hoi.txt`: Structured act/segment script (`HỒI I`, `Phân đoạn 1.1 (Hình ảnh: ...)`, `(Skit #1: ...)`).

---

## 2. Dynamic Adaptive Clustering (`90s – 240s` Golden Window)
`engine/scan_clusters.py` parses `kich_ban_chia_hoi.txt` dynamically without hardcoding act counts:
- **Target Cluster Size:** `90s – 240s` (`1.5 – 4.0 minutes`) and `<= 22 beats` per cluster.
  - At `37 fps` render speed, a `105s` cluster renders to Full HD MP4 in `~80 seconds`!
  - `10–18 beats` per `.js` module is the exact sweet spot where an AI agent can craft rich, bespoke 2D vector art for *every single beat* without cutting corners.
- **Skit Isolation:** Whenever a satirical dialogue block (`Skit #N`) appears inside an Act, `scan_clusters.py` isolates it into its own cluster (`cum_XX_Skit_N`) so it gets its own comedic pacing and `bgm_satire_skit.wav` score.

---

## 3. Zero-Drift (`0.000s`) Audio Slicing
When `python engine/scan_clusters.py --episode <EP_ID> --cluster <CLUSTER_ID>` runs:
1. If `CLUSTER_ID` follows an earlier sliced cluster, its search window starts at the **exact `source_mp3_t1`** of the previous cluster (`0.000s` inter-cluster gap).
2. `faster_whisper` (`word_timestamps=True`, `int8` CPU) locates word boundaries for each beat in `kich_ban_loi_dan.txt`.
3. `find_nearest_silence_valley()` scans a `25ms` sliding RMS energy window (`5ms` step) around each cut point so cuts **never clip a spoken Vietnamese consonant or vowel**.
4. Sample-accurate frame slicing writes `48000 Hz` Stereo `pcm_s16le` `.wav` files and records exact `nframes / 48000.0` float timestamps into `episodes/<EP_ID>/2_assets/timelines/timeline_<CLUSTER_ID>.json`.

---

## 4. Strict `.cache/` vs `2_assets/` Separation
| Artifact Type | Exact Location | Git / Backup Policy |
| :--- | :--- | :--- |
| Archival Photos (`.jpg`/`.png`) | `episodes/<EP_ID>/2_assets/photos/` | **Permanent** (Lightweight, `< 5 MB`) |
| Cluster Plan & Beat Timelines (`.json`) | `episodes/<EP_ID>/2_assets/timelines/` | **Permanent** (Lightweight text, `< 100 KB`) |
| Sliced Cluster Voice (`voice_<cluster>.wav`) | `.cache/<EP_ID>/<cluster>/` | **Disposable Cache** (Auto-regenerated by `mix_audio.py` or `scan_clusters.py`) |
| Individual Beat WAVs (`beats_wav/beat_XX.wav`) | `.cache/<EP_ID>/<cluster>/beats_wav/` | **Disposable Cache** |
| 3-Layer Mastered Audio (`mixed_<cluster>.wav`) | `.cache/<EP_ID>/<cluster>/` | **Disposable Cache** |
| Raw Peak PNG Frames (`peak_01..NN.png`) | `.cache/<EP_ID>/<cluster>/peaks/` | **Disposable Cache** |
| Stitched Peak-Zoom QA Sheet & Final MP4s | `episodes/<EP_ID>/4_output/` | **Permanent Deliverable** |
